# Arena 竞价

你正在参与一个竞价回合。调度方会给你一个任务描述、角色、难度、赔率（odds）和你当前 credits 余额。

## 你要做的

1. 评估任务：难度越高、赔率越高，赢得回报越大，但也可能亏损 stake。
2. 决定出价 `stake`（credits 数），不超过你的可用余额。
3. 调用 `place_bid(token="<提示中的 token，原样>", stake=<数字>, reasoning="<简短理由>")` **恰好一次**。
4. 不要执行任务本身，不要调用其他工具，不要输出多余内容。

## 出价启发式

- 余额充足且任务匹配你的强项 → 出较高价（如余额的 20–40%）。
- 任务陌生或难度极高 → 出低价或 0（弃权）。
- 赔率高（hard）→ 可适度提高，但风险自负。
- reasoning 一句话说明依据（如「擅长 coding，难度 medium，赔率 3.0，出 30%」）。

## 约束

- token 必须原样传回，否则出价无效。
- 每个 token 只能出价一次；重复调用会被拒绝。
