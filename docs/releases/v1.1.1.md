## 升级必读（v1.1.0 → v1.1.1）

1. **v1.1.0 的 Release tgz 资产是修复前代码**：解包做 PTL CLI 可用，但按 compose 部署会复现 Dockerfile 构建失败与 strict 启动失败——容器部署请用 v1.1.1 资产或 `git clone` main。
2. 已按 v1.1.0 文档启动过 compose 的用户：`git pull` 后重新 `docker compose build`，并确保 `.env.pth.secrets` 齐全（缺任一会 fail-closed，属预期）。
3. 验证③的脚本现在需要容器名：`bash scripts/check-sandbox-env.sh pi-platform-sandbox-1`。

## 安装路径

1. **容器部署（推荐）**：
   ```bash
   git clone https://github.com/Phenol1145/pi-triple.git && cd pi-triple
   cp deploy/.env.pth.secrets.example deploy/.env.pth.secrets   # 填真实值
   docker compose --env-file deploy/.env.pth.secrets -f deploy/docker-compose.yaml up -d postgres redis
   docker compose --env-file deploy/.env.pth.secrets -f deploy/docker-compose.yaml up -d pi-platform sandbox
   ```
   验证三连见 [deployment.md](../pth/deployment.md#2-安装步骤)。
2. **Release 附件**：
   ```bash
   curl -LO https://github.com/Phenol1145/pi-triple/releases/download/v1.1.1/pi-triple-v1.1.1.tgz
   shasum -a 256 pi-triple-v1.1.1.tgz   # 8097f6098468ead72c6ca66115d0f3b901992d97817e00a34af7240e79349c2a
   mkdir pi-triple-v1.1.1 && tar -xzf pi-triple-v1.1.1.tgz -C pi-triple-v1.1.1 && cd pi-triple-v1.1.1
   npm ci && npm link && ptl --version  # 包内已含构建产物 dist；CLI 开箱即用
   ```
   只装 CLI 可 `npm install -g pi-triple-v1.1.1.tgz`。
3. **源码开发**：clone 后 `npm ci && npm run build && npm link`（dist 不入 git，必须先 build；顺序为 shared→infra→…→root）。
