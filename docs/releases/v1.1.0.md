## 本版里程碑

### 1. 模块化 v2 全部完成（P0–P3 收账）
- `contracts / tasking / runner / execution / catalog / bootstrap / application / gateway` 模块边界落地；
- `framework-contracts.md` 框架契约 + `check:pth-boundaries` 机器强制（0 违规）；
- 五份旧计划退役（Retirement notices），全量证据链入 `2026-08-15-pth-modularization-v2.md`。

### 2. 沙箱加固 Side B 收账
- 生产 grant 接线（`PTH_EXECUTION_GRANT_SECRET` 双侧签名、worker 级签发）；cancel-ack-release 竞态闭环；
- S1 观测与容量（kernel 池 L3 / gdb 会话 / Bash StreamJob / degraded 阈值）；S2-5 hostile matrix 定稿实跑。

### 3. 全部流程 trigger 化
- `TriggerEngine` 原生 action + 任务 action 并存；`registerAction`、动态 `nextMs`、`listTriggers`；
- 统一事件桥（子进程 EventBus → IPC → ActivityHub，batch/kernel/worker 事件词汇）；
- optimizer deopt / PerfAutopilot / batch-scaler / claim-reaper / watchdog / flow-resolver
  全部收编为 **schedule trigger 指令**（`system-triggers.ts` 集中注册）；
- PerfAutopilot R2 回滚接线修复（原生产路径从未回滚）。

### 4. 任务模板统一收口（A+）
- `TASK_TEMPLATES` 成为唯一任务模板契约 + `resolveTemplateTask` 共享解析器；
- 发布 API / TriggerEngine / PerfStrategy 三消费方收口；`TriggerDef.task` 支持 `{template, params}` 引用（事件变量注入）；
- `memory-sweep` 内部提示词迁入模板库（`hidden`）；`pth submit --template/--param`。

### 5. 配置集中化 + 密钥安全基线
- `src/pth/config/`：**107 键 typed schema**（类型/默认值/secret/runtime/scope）为唯一真相源；
- ConfigCenter 权威化：schema 默认值兜底、runtime `perf.set`、**snapshot 密钥打码**（worker 不再能读 secret）；
- `src/pth` 内 `process.env.PTH_*` 直读清零（72 处迁移），`check:pth-config` 防回潮并入 lint；
- 统一 `deploy/.env.pth.secrets`（gitignored）+ 全部密钥 `:?` fail-closed + Redis AUTH + `PTH_CONFIG_STRICT=1`。

## 行为/运维变更（升级必读）

1. **compose 启动命令变化**：
   ```bash
   cp deploy/.env.pth.secrets.example deploy/.env.pth.secrets   # 填真实值
   docker compose --env-file deploy/.env.pth.secrets -f deploy/docker-compose.yaml up -d
   ```
