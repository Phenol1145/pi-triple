# pi-triple v1.1.2 —— 全模块结构专项优化收账

> 发布时间：2026-08-17 · tag `v1.1.2` · 附件 `pi-triple-v1.1.2.tgz`
> 门禁：全量 vitest **234 文件 / 1903 用例绿 / 9 hostile skip**；lint（boundary + pth-config）0 违规；
> build 干净；模块审计 **bucket cycles none / 文件级环 0 / >500 LOC 文件 0**。

## 本版内容（四阶段模块专项，均为结构/配置优化，行为兼容）

1. **依赖环全部断开**
   - PTH 7-module SCC 拆解：`kernel` 不再反向依赖 `application/catalog/impls/tasking/runner/bootstrap`；
   - `task-loop` / `batch-process` 移入 `bootstrap`（组合根装配）；
   - `role-router` 改走 contracts 端口（catalog `setRuntimeCatalog` 自动注入）；
   - 具体核工厂经 `kernel-factories` 端口注入；内置角色/空间定义下移 kernel（impls 保留 re-export）；
   - facade↔assembly、kernel 4 文件环、components↔programs、shared session↔tmux 全部断开。

2. **超大文件全部拆分**
   - 11 个 >500 LOC 文件降至阈值内：agent-engine 980→476、agent-loop 912→500、
     agent-tools 593→138、components/store 617→475、pit-providers 595→201、
     shared/config 564→440、sandbox exec-api/kernel-host、bridge-client、mailbox index 等。

3. **pth-sandbox 配置收口**
   - 新增 `packages/pth-sandbox/src/config.ts`（`loadSandboxConfig` 22 键 typed accessor）；
   - 包内 23 处 `process.env.PTH_*` 直读归零；`check:pth-config` 防回潮守卫扩展到 sandbox src。

4. **framework（PTL）整理与测试补强**
   - `commands↔pi-scan↔session-provider`、`backend↔docker-backend` 文件环清零；
   - 新增 `packages/framework/test`：容器后端注册表 + bridge-client 公共面测试。

## 行为/运维变更（升级必读）

1. `bootstrap/**` 成为组合根：允许绑定 `kernel/storage/*` adapter（`pth-boundaries-core.ts` 规则与
   `framework-contracts.md` 已同步）。其余 framework 模块仍只走公共 index。
2. pth-sandbox 配置直读收口：新增机器强制——sandbox src 内除 `config.ts` 外不得直读 `process.env.PTH_*`。
3. 默认值说明：`PTH_MEMORY_BRIDGE` 在 sandbox 侧默认自循环 8080（host/batch 侧同键默认见 schema）；
   `PTH_EXEC_PRIVATE_ROOT` 未注入时保持不启用（Dockerfile/compose 已注入时行为不变）。

## 安装路径

1. **容器部署（推荐）**：
   ```bash
   git clone https://github.com/Phenol1145/pi-triple.git && cd pi-triple
   cp deploy/.env.pth.secrets.example deploy/.env.pth.secrets   # 填真实值
   docker compose --env-file deploy/.env.pth.secrets -f deploy/docker-compose.yaml up -d postgres redis
   docker compose --env-file deploy/.env.pth.secrets -f deploy/docker-compose.yaml up -d pi-platform sandbox
   ```
2. **Release 附件**：
   ```bash
   curl -LO https://github.com/Phenol1145/pi-triple/releases/download/v1.1.2/pi-triple-v1.1.2.tgz
   shasum -a 256 pi-triple-v1.1.2.tgz   # 4a1e2092d552cc24f754db95cea59664423097beaa0b28c2dfe5a155aca04861
   mkdir pi-triple-v1.1.2 && tar -xzf pi-triple-v1.1.2.tgz -C pi-triple-v1.1.2 && cd pi-triple-v1.1.2
   npm ci && npm link && ptl --version  # 包内已含构建产物 dist；CLI 开箱即用
   ```
   只装 CLI 可 `npm install -g pi-triple-v1.1.2.tgz`。
3. **源码开发**：clone 后 `npm ci && npm run build && npm link`。
