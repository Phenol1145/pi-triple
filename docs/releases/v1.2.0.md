## 本版内容

### 1. N29 最小可信知识摄入内环（核心新增，MIN_INNER_LOOP_GO）

从人类签名 Trust Policy 到官方知识产出的完整单来源内环首次达到 GO：

- **信任源**：Ed25519 人类签名 Trust Policy（canonical digest + detached signature + read-only keyring）；
  `POLICY_VERIFIED_BRAND` 运行时 attestation——结构同形伪造、无效签名/digest、错 principal/issuer
  全部零行拒绝；repository 注入 verifier 时每次安装重新验签。
- **调度与聚合**：Subscription → due scanner → IntakeRun lease（generation/token/rowVersion）；
  Run 阶段迁移冻结矩阵（`RUN_STAGE_TRANSITIONS`）；领域提交 + Run CAS + 下一阶段 outbox 同一事务；
  side-effect tenant 由 CAS 通过行的聚合上下文盖章，跨 tenant 入队 fail closed。
- **抓取/准入**：policy-bound HTTPS fetch（逐跳 origin/pathPrefix/重定向/预算/条件请求）；
  P1-1 特殊 IP 分类补齐（IPv4-mapped 全展开、IPv6 multicast/link/ULA、benchmark/documentation/TEST-NET 全拒）；
  外部字节先 raw-quarantine，admitted 必须同 tenant/subscription 派生且 use decision=allow，
  raw/normalized hash 与 byteLength 由服务端重算。
- **抽取与双核验**：生产 extractor + strict KnowledgeIngestor（EvidenceReference 精确 locator/quoteHash/
  artifactHash/policyDecisionDigest 绑定）；VerificationPlan 双 check（domain + adversarial），
  principal 与 execution 双重分离；evidence quote 服务端复算后才进入 review。
- **晋升与消费**：official 只能经不可省略 evaluator 的 Promotion Service（legacy 空 digest/evidence
  兼容路径删除；内部推理知识需显式 internal origin）；exact-hash 原子晋升 + supersedes/stale 依赖账；
  production Broker/KnowledgeContext 可见性一致。
- **重爬闭环**：initial / unchanged（304 零成本 + use-policy 先决）/ changed（旧 official 先撤出 +
  supersedes）三路径；policy deny/过期/撤销在 unchanged 也 fail closed。
- **模式门**：`PTH_KNOWLEDGE_INTAKE_MODE=off|draft|full`。draft 只到 private draft/open plan（无 promote
  handler）；full 启动必须出示绑定当前 commit 的 `MIN_INNER_LOOP_GO` envelope（`assertIntakeFullAcceptance`）。
- **真实性验收**：G8-a 双 OS drainer；G8-b artifact 写入前 / aggregate+outbox commit 后 / handler 写结果后
  三个故障点真实子进程 kill -9 后由新进程读 PG 恢复；G9-a/b 受控 TLS 全组合；G9-c release canary 在
  人类批准的真实公网来源 `https://gpe.wikipedia.org/wiki/Wikipedia` 上完成 initial fetch → official
  （DoH 真实公网 IP + SSRF pin + evidence 可回放）；G10 trust/evidence/digest/lease/stale 五项门禁
  全部经真实生产注入缝 sabotage（门移除即失守、基线拒绝）。
- **验收权威**：`docs/pth/n29-minimal-intake-acceptance.json`（`MIN_INNER_LOOP_GO`，绑定 `c6d0156`）；
  独立复核反馈 `n29-minimal-intake-reacceptance-feedback.md` 的 P0-1~P0-9、P1-1~P1-3 全部关闭。

## 行为/运维变更（升级必读）

- **新增配置**：`PTH_KNOWLEDGE_INTAKE_MODE=off|draft|full`（默认 **off**）。本版只发布
  `MIN_INNER_LOOP_GO` envelope，不自动切换生产默认值；启用 `full` 需部署审批，且启动门会校验
  envelope 与当前 commit 的绑定。
- **Trust Policy 安装边界收紧**：任何未经验签/attestation 的 policy 安装零行；依赖手工 policy 镜像
  的工具若绕过正式 service 会立即失败。
- **knowledge official 写口收紧**：raw store 直写 official、无 evaluator `promoteOfficial()`、
  legacy 空 evidence/digest 晋升全部移除；内部推理知识需显式 `origin=internal` 契约。
- **acceptance 口径**：N29 acceptance driver 是全部门禁 + realism gates + 31 sentinel 的唯一终审权威；
  full regression 允许的 skip 仍仅为既有 `sandbox-security.integration.test.ts` 9 条冻结 skip。
